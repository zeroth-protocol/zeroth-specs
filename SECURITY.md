# Security Policy

Do **not** open a public issue for a suspected vulnerability.

Until Zeroth publishes a dedicated external security contact, use GitHub Private Vulnerability Reporting / Security Advisories on the affected repository where enabled. If private reporting is not enabled, contact an authorized Zeroth maintainer privately.

A formal public bug-bounty scope will be published before mainnet release. Pre-mainnet repositories may include research or experimental code and must not be treated as production-ready unless explicitly marked.

Zeroth follows coordinated vulnerability disclosure. Security-sensitive details may remain embargoed until remediation and downstream protection are complete.
