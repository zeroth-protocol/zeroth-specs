# Contributing

Thank you for contributing to The Zeroth Protocol.

1. Search existing ZIPs and issues before proposing protocol changes.
2. Use a ZIP for protocol-semantic or standards changes.
3. Keep implementation changes aligned with the current public specification.
4. Clearly identify research assumptions and unresolved security questions.
5. Never include credentials, private infrastructure, unreleased vulnerability details, or confidential research.

Pull requests should be coherent, include tests/vectors for behavior changes, reference applicable specifications, and avoid direct commits to protected release branches.

AI-assisted contributions must be reviewed by a human contributor who takes responsibility for correctness, provenance, licensing, and security.
