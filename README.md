# Zeroth Protocol Specifications

Canonical public specifications for **The Zeroth Protocol**.

Status: pre-mainnet research and specification. Nothing here should be interpreted as a claim that production consensus or mainnet is complete.

Approved evolution principle: Ethereum settlement → Arbitrum execution → dedicated Zeroth Rollup/appchain when justified → PQ-native Zeroth settlement only after explicit readiness criteria are met.

PoVW remains distinct from blockchain consensus.
